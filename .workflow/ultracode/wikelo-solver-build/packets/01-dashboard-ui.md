# Packet 01: dashboard UI

## Objective
Implement the approved dark Option B recipe dashboard and browser-side interactions.

## Ownership
`app/page.tsx`, `app/layout.tsx`, `app/globals.css`, `app/components/` only.

## Do
Create accessible UI with realistic clearly demo-labelled data. Provide search, sort, filters, owned/farmable flags, availability filtering and missing price display.

## Do not
Do not edit database, API, hosting, tests, package files or use browser storage as a durable source of truth.

## Handoff format
List files changed, key interactions, validation and risks.
